# Todo App

A command-line to-do app written in Python.

## Features

- Add a task
- Shown all tasks
- Delete a task
- Save tasks in a JSON file
- Handle invalid input

## How to run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```
python todo.py
```
